# 📄 Sistema de Orçamentos para Serviços de Refrigeração

Aplicação desenvolvida em **Python** para facilitar a criação de orçamentos para uma empresa de serviços de refrigeração.

O sistema possui uma interface gráfica onde o usuário pode cadastrar os serviços de mão de obra e seus respectivos valores. Ao finalizar o cadastro, a aplicação gera automaticamente um **orçamento em PDF**, contendo os serviços especificados e o valor total.

## 🎯 Objetivo

Facilitar a criação de orçamentos e reduzir o trabalho manual necessário para organizar os serviços e calcular os valores apresentados ao cliente.

## ⚙️ Como funciona

O processo é simples:

```text
👤 Usuário
   ↓
🖥️ Interface do programa
   ↓
📝 Cadastro dos serviços
   ↓
💰 Definição dos valores
   ↓
🧮 Cálculo do total
   ↓
📄 Geração do orçamento em PDF
```

O usuário informa os serviços de mão de obra que serão realizados e seus respectivos valores.

A aplicação organiza as informações, calcula o valor total e gera um documento PDF detalhando os serviços incluídos no orçamento.

## 🛠️ Tecnologias utilizadas

* **Python**
* Interface gráfica
* Geração de arquivos PDF

## 💡 O que o projeto demonstra

O projeto foi desenvolvido com foco em transformar uma necessidade prática em uma aplicação simples e funcional.

Entre os conhecimentos aplicados estão:

* Desenvolvimento de aplicações em Python;
* Criação de interfaces gráficas;
* Entrada e validação de dados;
* Manipulação de valores;
* Cálculo de totais;
* Organização de informações;
* Geração automática de documentos PDF.

## 📄 Resultado

O orçamento gerado apresenta os serviços cadastrados e seus respectivos valores, permitindo que as informações sejam organizadas em um documento pronto para apresentação ao cliente.

## 📌 Contexto

Este projeto foi desenvolvido para uma empresa do segmento de refrigeração, com o objetivo de facilitar o processo de elaboração de orçamentos.
